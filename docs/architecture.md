# Архитектура Forge

## 1. Основные компоненты

Предварительно архитектура Forge разделяется на следующие компоненты:

- **CLI** — интерфейс взаимодействия с пакетным менеджером.
- **Package** — представление пакетов и обработка рецептов.
- **Dependency** — разрешение зависимостей и построение порядка сборки.
- **Build** — выполнение процесса сборки пакетов.
- **Store** — управление хеш-адресуемым хранилищем.
- **Profile** — формирование окружений из выбранных пакетов.
- **Initramfs** — подготовка файловой системы и создание initramfs.
