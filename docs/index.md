## Содержание

- [Архитектура](architecture.md) — общая структура проекта, основные компоненты и их взаимодействие.

- Руководство по настройке среды разработки.
- Формат описания пакетов и рецептов.
- Использование командной строки Forge.
- Алгоритм разрешения зависимостей.
- Устройство хеш-адресуемого хранилища.
- Управление профилями пакетов.
- Формирование минимального Linux initramfs.
